# Hermes Desktop Light Builder

**Языки:** [English](README.md) · [简体中文](README.zh.md) · [繁體中文](README.zh-hant.md) · [日本語](README.ja.md) · [العربية](README.ar.md) · Русский · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md)

Этот репозиторий собирает **Hermes Light** — версию настольного приложения [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) для подключения к удалённому серверу — для Mac с Apple Silicon. Здесь хранятся собственная документация и процесс сборки GitHub Actions. Каждая сборка использует конкретный коммит ветки `main` исходного проекта. Это сборки из снимков исходного кода, а не официальные релизы проекта.

## Загрузка и подключение

1. Загрузите DMG для Apple Silicon со страницы [Releases](https://github.com/royzheng/hermes-desktop-light-builder/releases). Выпуски с суффиксом `-unsigned.1` — неподписанные предварительные версии для **ручной установки**.
2. Перетащите **Hermes Light.app** в `/Applications` и откройте приложение.
3. При первом запуске выберите **Connect to existing Hermes**, введите HTTPS-адрес своего сервера и нажмите **Test connection**. Затем войдите через приложение и примените подключение. Ни репозиторий, ни пакет приложения не содержат пароль или личный адрес вашего сервера.

Hermes Light не включает серверную часть Hermes на Python и `agent-payload`. Сборка не запускает исходный `install.sh` и не меняет ваш сервер. macOS Gatekeeper может заблокировать неподписанную версию. Проверив источник загрузки, разрешите запуск в «Системных настройках → Конфиденциальность и безопасность» либо выполните `xattr -cr` для приложения.

## Сборки и обновления

[Процесс сборки](.github/workflows/build-light.yml) запускается ежедневно в **03:17 UTC**; его также можно запустить вручную в Actions. Он собирает Light из конкретного коммита, проверяет идентификатор приложения, состав пакета, настройки обновления и файлы выпуска, а затем публикует их в Releases этого репозитория. Если изменения исходного проекта ломают сборку или проверки, публикация останавливается.

При создании этого репозитория последний стабильный тег исходного проекта ещё не содержал конфигурацию упаковки Light, поэтому процесс отслеживает `main`. Версия определяется временем коммита по UTC, а точный коммит указан в примечаниях к выпуску. Python используется в CI лишь как временный инструмент сборки; готовое приложение не содержит локальную среду Python.

Файл `app-update.yml` внутри приложения указывает на `royzheng/hermes-desktop-light-builder`. Однако **автоматическое обновление macOS из неподписанных предварительных версий ненадёжно**, и такие версии не становятся последним официальным Release на GitHub. Первый подписанный и нотариально заверенный выпуск необходимо установить вручную поверх предварительной версии; затем следует проверить обновление на следующем подписанном выпуске. Список секретов GitHub Actions для подписи и технические подробности приведены в [английском README](README.md#enable-signed-releases).
